About This Project

This is a full-stack URL shortener built to simulate a real-world backend system. It takes long URLs and converts them into short, shareable links that redirect instantly.

The system is designed with performance and scalability in mind. It uses caching, rate limiting, and optimized database operations to handle high traffic efficiently.

Key features include fast redirects, click tracking, 30 days link expiry, and analytics for each shortened URL.

Tech Stack

  • Backend: Java 21, Spring Boot
  • Database: MySQL
  • Caching & Rate Limiting: Redis
  • Frontend: Angular
  • Deployment: Docker
